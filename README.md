# English Quotes Presentation

This repository contains a slide deck styled for a clean, modern English quote presentation. Open `index.html` in a browser to view the slides. The design matches a minimalist PowerPoint / Canva look and is ready to be copied into PowerPoint or Canva for final export.

## Slides included
- Cover
- Contents
- Dream & perseverance
- Perseverance continuation
- Action & effort
- Action & effort continuation
- Mindset & life
- Quote summary

## Suggested export workflow
- Open `index.html` in a browser.
- Use browser print or save as PDF.
- Import into Canva or PowerPoint and export as `.pptx` if needed.

## Design theme
- White background
- Black/dark gray typography
- Gold accent color: #D4AF37
- Large centered quotes with generous spacing
